# BeHappy Play Store listing (draft)

Host `privacy.html` at a public HTTPS URL and paste it into Play Console before review.

## Short description (80 characters max)

Daily mood check-in and 3 things for today. Free, with optional Remove Ads.

## Full description

BeHappy is a 30-second daily companion.

• Tap how you feel
• Write up to three things for today
• Optionally note what went well
• See your streak and a mood calendar

Everything is free. Your entries stay on your phone. The only purchase is a one-time Remove Ads option. We never lock features behind a paywall.

Not a medical or mental-health treatment app.

## Category

Lifestyle (or Health & Fitness)

## Content rating

Everyone. No user-generated public content.

## Data safety (draft)

- Collected: advertising ID (AdMob, if ads are shown); purchase token (Play Billing, if the user buys Remove Ads)
- Not collected: journal/mood contents (on-device only)
- Encrypted in transit: AdMob/Play traffic uses HTTPS
- Users can request deletion: uninstall the app
